# Devkit
A C "library" that gives the user some handy tools from 
other languages (like Java) that offer a ready-to-use implementation of lists, arrays, sets and so on
that are missing in standard C. I do not recommend to use it seriously as i do not assure that this
library has perfomant or reliable implementations, though it should work if used as intended.

As the library gets more and more updates, everything should become faster and less prone to break.
